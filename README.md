# SAMGA Care Bridge — 콘셉트 프로토타입

삼가 '서비스기획팀장' 면접용 신규 아이템 **SAMGA Care Bridge** 클릭 프로토타입.
기업 HR을 위한 **임직원 경조(장례) 지원 오케스트레이션** 개념 데모입니다.

- 단일 페이지 웹앱 (HTML/CSS/JS, 외부 프레임워크·라이브러리 없음)
- 화면 1 — HR 케이스·정책 콘솔 (관계별 정책 자동 적용, 상태 전이)
- 화면 3 — 이행·정산·기업 리포트 (KPI·SLA 추이·비용 대사, 순수 CSS/SVG 차트)
- 화면 2 — 임직원·유가족 동의 (클릭 불가 와이어프레임 썸네일)

## 가드레일
- 모든 수치·회사·인물은 **가상**입니다 (Concept Prototype).
- 무동의 부고 자동수집 안 함 · 자동 경조금 승인 안 함 · 법률/세무 대리 안 함.
- 지불자 = 기업 HR, **유가족 직접 과금 없음**.
- AI 판단은 참고이며 담당자 최종확인.
